## 👨‍💻 About Me

I'm a software developer focused on building **cloud-native backend systems** and automating everything around them.
My core stack is **Java and Spring Boot**, deployed with **Docker and Kubernetes** on **Microsoft Azure**, with infrastructure managed as code through **Terraform** and delivered through **CI/CD pipelines**.

Oracle-certified in Java (OCA & OCP, Java SE 8) and CompTIA-certified in IT operations and networking, I bring both the development and the operations side of the picture.
